## Code Improvements

**1. Copy Trader: `quiver_fail_count` is never reset on success**, so after a transient outage resolves, the stale count could suppress or distort future alerting logic.

**2. Copy Trader: The 401 error is specifically an auth failure**, not a transient network error. The alert message should distinguish auth failures (401/403) from transient ones (5xx/timeout) since they require different remediation.

**3. Wheel: The `last_close_ts` is stored as a UTC string but compared against `datetime.utcnow()`** — this works today but is fragile since `datetime.utcnow()` is deprecated in Python 3.12+ and naive. It should use `datetime.now(timezone.utc)` consistently with the rest of the codebase.
