## Code Improvements

**1. Copy trader: alert on repeated API auth failures rather than silently degrading forever.**

The Quiver API has been 401-ing for 3 days. The bot logs a warning each time but never escalates. After N consecutive failures, it should surface a more visible alert (print to stdout with a distinctive prefix, so GitHub Actions job logs catch it).

**2. Wheel: the `STOP_LOSS_PCT` local variable shadows the module-level constant inside `check_early_close`, making it invisible to the stop-loss check outside that function. It should be removed — the module-level constant already defines it.**

**3. Wheel: `last_close_ts` is only written on early-close (50% profit), not on stop-loss exits. A stop-loss exit into a bad market is exactly when the cooldown matters most.**
